# Веб-интерфейс для кода Рида-Маллера

Небольшое Flask-приложение для кодирования и декодирования двоичных кодов Рида-Маллера `RM(r, m)`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run
```

После запуска откройте `http://127.0.0.1:5000`.

## Возможности

- вычисление параметров `n`, `k`, `d`, `t`;
- кодирование сообщения длины `k`;
- имитация ошибок по позициям;
- точное декодирование по минимальному расстоянию при `k <= 20`;
- рекурсивное декодирование по конструкции Плоткина как запасной режим для больших `k`;
- восстановление информационного сообщения из декодированного слова.
